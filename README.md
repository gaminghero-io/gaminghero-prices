# Gaming Hero prices

Hourly WoW Forever auction house prices from the Blizzard API, used by gaminghero.io.

- `data/forever-eu.json`, `data/forever-us.json`: current prices per item (copper). `a` = Alliance, `h` = Horde, `n` = Blackwater (neutral). `min` = cheapest, `mkt` = market value (average of the cheapest 15% of listed quantity), `med` = median, `qty` = total listed.
- `data/forever-*-history.json`: one market price per day for the last 45 days.
- `data/item-names.json`: item ID to name.
